## 使用

### 基本用法

1. **上传照片并说明类型**：
   ```
   帮我看看这个面相 [上传人脸照片]
   ```

2. **也可以只上传照片**：照片类型清楚时，技能会自动选择对应规则；类型不明、包含多个可能部位或与文字要求不符时，会先向你确认。

3. **没有上传照片时**：技能会先请你上传。若你还没说要看哪种相，会列出面相、手相、骨相、体相供你选择，再请你提供对应照片。

分析前确认照片与类型后，技能才会读取规则。若当前环境有能基于原图进行图像标注的工具，会生成带引线的原图说明图；否则以“老夫”的家常口吻做文字分析，并说明参考出处。

### 支持的分析类型（tenpai-kanxiang）

| 类型 | 说明 | 照片要求 |
|------|------|---------|
| **面相** | 分析五官、三庭、十二宫、气色 | 正面人脸照最佳；侧脸只谈可见轮廓 |
| **手相** | 分析掌线、指形、掌丘、色泽 | 手掌正面照片 |
| **骨相** | 分析头骨、体骨、九骨结构 | 能看出骨骼轮廓的照片 |
| **体相** | 分析体型、体态、气质 | 全身或半身照片 |

## 使用示例

### 示例 1：有照片，类型明确（面相）

> 输入：`帮我看看这个面相 [上传人脸照片]`

```
用户 ❯ 帮我看看这个面相

看相技能 ❯ 哎，让老夫看看。照片里天庭比较开阔，眉骨也看得清楚。

按传统面相的说法，上庭常拿来谈早年根基和思路，眉骨这一带多说性情与决断。老夫挑照片里最明显的几处讲，不把话说死。具体这几处讲完，整体再看，这张脸给人的感觉偏沉稳，眉眼不算凌厉；按老说法讲性格，多半是个做事有分寸、不爱冒进的人。相关规则整理参考《麻衣神相》等传统面相资料。

（当前环境有能编辑原图的工具时，此处附一张原图引线标注图，标明天庭、眉骨等部位；每个标签分两行，上行写部位名，下行写一句简短外观描述，如“天庭／比较开阔”“眉骨／略突出”。用英文提问时，图内标签也用英文。没有合适工具时只给上面的文字解读，并说明未能生成标注图。）
```

## 功能特性

### 支持的相术类型

| 类型 | 分析维度 | 规则来源 |
|------|---------|---------|
| **面相** | 五官、三庭、十二宫、气色 | 《麻衣神相》《柳庄相法》《神相全编》 |
| **手相** | 掌线、指形、掌丘、色泽、纹路 | 《神相全编》《水镜神相》 |
| **骨相** | 头骨、体骨、九骨结构 | 《太清神鉴》《人伦大统赋》 |
| **体相** | 体型、体态、气质、步态 | 《冰鉴》《神相全编》 |

### 输出方式

- **跟随提问语言**：用户用中文问就用中文答，用英文问就用英文答；用户明确指定另一种语言时按指定语言。确认、分析、回退说明和图片标注都用该语言；英文回复时部位和宫位用通行英文译名，必要时括注中文。
- **先细节，后总体**：先讲具体部位和可见特征，最后再收总体观感与性格；不先下“这人怎样”的总体结论。图片标签只写具体可见特征，总体判断和性格评价放在文字末尾。
- **老夫口吻**：以“老夫”自称，用像家常聊天的方式讲解，偶尔带“啧”“哎”等语气词。
- **按需展开**：围绕用户问的部位和问题讲，不机械套用固定报告模板。
- **出处说明**：主要判断附参考书名；只写知识库能支持的书目归属，不编造篇章、页码或原文。
- **原图标注图**：当前环境有能基于用户原图编辑标注的工具时，生成保留人物原貌、用引线指向分析部位的说明图。每个标签分两行：上行写部位名，下行写一句简短外观描述（如“出纳宫／唇略薄”“天庭／比较开阔饱满”）；没有合适工具时只给文字解读，并如实说明。

### 技术原理

```
检查图片 → 判断类型并在必要时确认 → 读取规则 → 分析可见特征
         → 尝试原图引线标注 → 交付标注图或文字解读
```

1. **检查图片**：没有可用图片时，先请用户上传；没说类型时，先列出四类相术供选择。
2. **确认类型**：图片清楚且与请求一致时直接继续；类型不明、多个部位或图文不符时先向用户确认。
3. **读取规则**：确认后读取面相、手相、骨相或体相对应的规则文件。
4. **分析特征**：只解读照片中清楚可见的部位，区分可见特征与传统说法。
5. **交付结果**：可用图像编辑工具时附原图引线标注图；否则给出老夫口吻的文字分析。

## 注意事项

### ⚠️ 重要提醒

- **本分析仅供文化参考和娱乐**：相术属传统文化，现代科学尚未证实其预测能力
- **请理性看待**：人生道路主要取决于个人努力和选择
- **不做绝对化断言**：所有分析均为概率性参考，非绝对命运
- **不作医疗判断**：肤色、掌纹或骨骼特征不能用于诊断；如有健康问题，请咨询专业医生

### 📋 使用限制

- 不预测具体事件或日期（如"何时结婚"、"何时发财"）
- 不涉及政治敏感话题
- 不宣扬迷信色彩
- 输出保留文化参考提示，不把相术说成科学结论

### 📷 照片要求

- **清晰度**：照片应清晰可见，避免模糊、遮挡
- **光线**：避免光线过暗或强光直射
- **角度**：正面照片最佳；侧脸照只分析该角度能看到的轮廓
- **隐私**：请勿上传包含他人隐私的照片

## 常见问题

### Q：分析结果准确吗？
**A**：相术是传统文化的一部分，可作为参考，但不宜迷信。现代科学对相术的预测能力尚无定论。建议将分析结果作为娱乐和文化参考，理性看待。

### Q：可以上传哪些类型的照片？
**A**：支持人体部位照片，包括人脸、手掌、全身等。照片应清晰可见，避免模糊、遮挡、光线过暗等问题。

### Q：分析需要多长时间？
**A**：通常在几秒到十几秒内完成分析。

### Q：可以多次上传照片分析吗？
**A**：可以。每次分析都是独立的，可以多次上传不同照片进行分析。

### Q：分析结果会保存吗？
**A**：不会。每次分析都是实时的，不会保存您的照片或分析结果。

### Q：支持哪些相术类型？
**A**：目前支持面相、手相、骨相、体相四大类。未来可能扩展更多类型。

## 写在最后

相术，是古人观察人与自然的智慧结晶。

它不是迷信，而是一种系统化的经验总结。从面相看性格，从手相看倾向，从骨相看格局，从体相看气质——这些都是先民们对"人"这个复杂系统的一种理解方式。

你的性格、能力、运势，更多取决于你的选择、努力和际遇。相术分析可以作为一个有趣的参考，一个了解传统文化魅力的窗口，但绝不是人生的指南针。

真正的"改相"，不在外在修饰，而在内心修养。

正如《冰鉴》所言："一身精神，具乎两目；一身骨相，具乎面部。" 精神气质，才是相术的终极追求。
